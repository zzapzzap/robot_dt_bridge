# 안전 모드 — 서비스 · 토픽

정상 운영 / 감속 3단 / 일시정지 / 비상정지를 **하나의 모드 값**으로 다룬다.
설정은 서비스, 방송은 토픽이다.

---

## 1. 모드 정의

| 값 | 이름 | 실제 속도 | PLC 기록 |
|---|---|---|---|
| 1 | 정상 운영 | 100 % | `D2000=[1,0,0]` |
| 2 | 감속 1 (25 % 감속) | 75 % | `D3000=[1,0,0]` |
| 3 | 감속 2 (50 % 감속) | 50 % | `D3000=[0,1,0]` |
| 4 | 감속 3 (75 % 감속) | 25 % | `D3000=[0,0,1]` |
| 5 | 일시정지 (Hold) | 0 % | `D2000=[0,1,0]` |
| 6 | 비상정지 | 0 % | `D2000=[0,0,1]` |

> **표기 주의** — 이름의 `%` 는 **감속률**이다(에이시스 사양서 표기).
> 실제 속도 배율은 `speed_ratio` 필드를 쓴다. 감속 3 = 75 % 감속 = 속도 25 %.
> 이 둘을 헷갈리면 정반대 속도로 움직이므로, 코드에서는 항상 `speed_ratio` 를 쓴다.

## 2. 설정 — 서비스

```bash
# CLI (짧게)
ros2 run robot_bridge mode_cli 감속2 --reason "작업자 접근"
ros2 run robot_bridge mode_cli stop
ros2 run robot_bridge mode_cli 감속3 --hold 10        # 10초만 유지
ros2 run robot_bridge mode_cli 정상 --clear           # 정지 고정까지 해제

# 원형
ros2 service call /robot/loading/set_mode robot_bridge_msgs/srv/SetSafetyMode \
  "{mode: 3, source: 'operator', reason: '작업자 접근', hold_seconds: 0.0}"
```

| 필드 | 뜻 |
|---|---|
| `hold_seconds` | `0` = 다음 설정 전까지 무기한 · `>0` = 그 시간 뒤 자동 해제 |
| `clear_latched` | 기존 고정 지령을 먼저 풀고 적용. **정지 고정을 푸는 유일한 방법** |
| 응답 `accepted` | 우선순위에 밀리면 `false` 와 사유 반환 |

## 3. 조회 · 감시

```bash
ros2 run robot_bridge mode_cli --get        # 1회 조회
ros2 run robot_bridge mode_cli --watch      # 변화 시 한 줄씩
ros2 topic echo /robot/loading/mode         # 원본 메시지
```

## 4. 토픽 vs 서비스 — 언제 뭘 쓰나

| | 토픽 `RobotCommand` | 서비스 `SetSafetyMode` |
|---|---|---|
| 쓰는 쪽 | XDI · XAG — 계속 판단해서 쏘는 자동 로직 | 운전원 · 상위 시스템 · 시험 |
| 유지 | **300 ms 후 소멸** (주기 발행 전제) | **고정(latch)** — 풀 때까지 유지 |
| 의도 | "지금 이 순간의 판단" | "지금부터 이 모드로 두어라" |

자동 로직이 주기 발행을 멈추면 지령이 저절로 풀리는 게 안전하다. 반대로 운전원이
"감속 2로 두고 작업" 하려면 고정이 필요하다. 그래서 경로를 둘로 나눴다.

## 5. 중재 규칙

```
우선순위   정지 100 > 일시정지 80 > 감속3 60 > 감속2 40 > 감속1 20 > 정상 0
```

1. 높은 우선순위가 이긴다. 동순위면 **고정 > 토픽**, 그다음 최신
2. 서비스로 **정상 운영**을 요청하면 감속 고정도 함께 풀린다
3. 단 **정지 · 일시정지 고정은 `--clear` 없이는 안 풀린다** (안전상 의도)
4. PLC 링크 두절 시 `fail_safe`(기본 일시정지)가 **모든 지령보다 우선**

### 실제 동작 예

```
서비스 감속2 고정          → 감속 2 (50 % 감속)  50 %  [operator] 고정 무기한
0.4초 후 (토픽이면 소멸)   → 감속 2 유지                    ← 고정이라 안 풀림
XDI 정지 토픽 끼어듦       → 비상정지            0 %  [xdi]
XDI 소멸(0.3초)           → 감속 2 로 복귀                 ← 밑에 깔린 고정이 살아남
정상 운영 요청            → 정상 운영          100 %       ← 감속 고정 해제됨
정지 고정 후 정상 요청     → 거절 "우선순위가 낮아…"
정지 고정 후 --clear      → 정상 운영                      ← 명시적 해제
링크 두절                 → 일시정지 [watchdog]
```

## 6. Unity 표시

`/robot/<id>/mode_unity` (`Int32MultiArray[4]` = `[모드, 속도%, 링크정상, 고정여부]`)를
`RobotStateReceiver` 가 구독해 라벨에 표시한다.

```
운전   (op 1)
지령 감속 2 (50 % 감속) · 속도 50 % [고정]
```

**위 줄은 PLC 가 실제로 보고한 상태**, **아래 줄은 우리가 내린 지령**이다.
둘이 오래 어긋나면 명령이 안 먹고 있다는 뜻이므로, 현장 디버깅에 쓰인다.
